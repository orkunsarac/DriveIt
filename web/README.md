# DriveIt web

Run `npm install`, then `npm run dev`, `npm test`, or `npm run build` in this directory. A future host must provide SPA history fallback to `index.html`. No deployment is configured.

Copy `.env.example` to `.env.local`; Vite values are public. Never use a secret or service role key. Auth defaults off and accepts only the exact approved PROD URL plus a public key. The publishable key's project ownership must still be verified by configuration; its format alone cannot establish ownership. Password recovery is separately gated and requires an approved exact same-origin HTTPS `/sifre-sifirlama` redirect added to the Supabase allowlist. Preserve the Android callback entry. SMTP, domain, legal publication, signup and Group Drive remain closed. Support is unavailable until a new address is selected. Deletion is blocked pending the separately reviewable server proposal and secure browser receipt recovery in `server-proposal/`.

No production Auth settings, function deployment, or web publication is performed here. Live account operations require separate approval and isolated acceptance; avoid testing against production accounts.
